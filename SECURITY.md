# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Report a vulnerability privately

Do not open a public issue for a credential leak, path traversal, unsafe archive behavior, prompt-injection vector, or other security-sensitive defect.

Use [GitHub private vulnerability reporting](https://github.com/muujaa1000-jack/solo-business-validation-skill/security/advisories/new). Include the affected version, reproduction steps, impact, and any suggested mitigation. Remove real credentials and private user data from the report whenever possible.

The maintainer will acknowledge a valid report, investigate it, and coordinate disclosure through a GitHub Security Advisory when appropriate.

## Scope

This repository is an instruction-only Skill plus local validation and packaging scripts. Reports about a host product, model provider, or third-party installer should be sent to that project's security channel unless the issue is caused by this repository's content or artifacts.
